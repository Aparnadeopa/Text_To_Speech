# 🔊 Text to Speech GUI

A simple and lightweight **Text-to-Speech desktop application** built with Python, using `tkinter` for the GUI and `pyttsx3` for offline speech synthesis.

---

## 📸 Preview

The app opens a clean GUI window where you can type any text and have it spoken aloud using your system's built-in voice engine — **no internet required**.

---

## ✨ Features

- 🖊️ Type any text and hear it spoken instantly
- 👨 **Male** voice support
- 👩 **Female / Female 2** voice support
- ⚡ Fully **offline** — no API keys or internet needed
- 🪶 Lightweight with minimal dependencies

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python 3 | Core language |
| `tkinter` | GUI framework (built-in) |
| `pyttsx3` | Offline text-to-speech engine |

---

## 📋 Requirements

- Python 3.x
- `pyttsx3` library

---

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Aparnadeopa/Text_To_Speech.git
cd Text_To_Speech
```

### 2. Install dependencies

```bash
pip install pyttsx3
```

### 3. Run the application

```bash
python TTSGui.py
```

---

## 🎮 How to Use

1. Launch the app using `python TTSGui.py`
2. Type your desired text in the input box
3. Click **Submit** to hear the text spoken aloud
4. Use the **Male**, **Female**, or **Female 2** buttons to switch voices
5. Click **Close** to exit the application
